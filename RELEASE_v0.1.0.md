# Likelihood Index v0.1.0 — Experimental Reference Model

First public release of the **Likelihood Index**.

## Includes

- Reference Python implementation
- Core README and project framing
- Methodology notes
- Validation roadmap
- Example usage script
- Synthetic stress tests
- Contribution guide
- Repository visual assets

## Notes

This framework is **experimental / pre-validation**.

It is not positioned as a literal purchase-probability model or a replacement for MMM, incrementality, attribution, experimentation, or brand tracking. Instead, it is an open framework for asking whether a brand is becoming **more or less likely to be chosen**, and what evidence supports that read.

## Invitation

If you work in marketing science, media measurement, brand analytics, or behavioral research, please test the assumptions, challenge the weighting logic, propose refinements, and help improve the validation approach.
